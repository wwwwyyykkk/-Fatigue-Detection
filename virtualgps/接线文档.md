# 虚拟GPS模拟板 - 硬件接线文档

## 开发板型号
ESP32-S3-DevKitC-1 (独立板，区别于主控板)

---

## 引脚分配表

### 1. GPIO 按键 (6个独立按键)

| 按键 | GPIO | 功能 | 接线方式 |
|------|------|------|----------|
| SW1 | GPIO8 | 速度 = 0 km/h | 按键一端接 GPIO8，另一端接 GND (内部上拉) |
| SW2 | GPIO9 | 速度 = 80 km/h | 按键一端接 GPIO9，另一端接 GND (内部上拉) |
| SW3 | GPIO11 | 速度 = 150 km/h (超速) | 按键一端接 GPIO11，另一端接 GND (内部上拉) |
| SW4 | GPIO12 | 地点循环切换 | 按键一端接 GPIO12，另一端接 GND (内部上拉) |
| SW5 | GPIO2 | 司机切换 (1↔2) | 按键一端接 GPIO2，另一端接 GND (内部上拉) |
| SW6 | GPIO16 | 驾驶时长 +60min | 按键一端接 GPIO16，另一端接 GND (内部上拉) |

**注意**: 
- 内部上拉电阻已启用，按下读到低电平 (0)
- 去抖延时 50ms，循环扫描间隔 50ms

---

### 2. SSD1306 OLED 显示屏 (I2C接口)

| 信号 | GPIO | OLED引脚 | 说明 |
|------|------|----------|------|
| SDA | GPIO4 | SDA | I2C数据线 |
| SCL | GPIO5 | SCL | I2C时钟线 |
| VCC | 3.3V | VCC | 电源正极 |
| GND | GND | GND | 电源地 |

**I2C 地址**: 0x3C (默认，`config.h` 可调整)

---

### 3. SYN6288 TTS 语音合成模块 (软件模拟 UART)

| 信号 | GPIO | SYN6288引脚 | 说明 |
|------|------|------------|------|
| TX | GPIO13 | RX | ESP32 软件UART发送 → SYN6288 接收 |
| BUSY | GPIO7 | BUSY | SYN6288 忙信号 (高=正在播放) |
| VCC | **5V** | VCC | ⚠️ 必须 5V，不能接 3.3V！ |
| GND | GND | GND | 必须共地 |
| — | — | SPK+ | 接喇叭正极 (8Ω/0.5W) |
| — | — | SPK- | 接喇叭负极 |

**通信参数**: 9600bps 8N1，帧头 0xFD，GBK 编码，XOR 校验和

**注意**:
- 采用软件 bit-bang UART，**不占用任何硬件 UART 外设**
- 发送时短暂关中断保证时序（约 104µs/bit，一帧 ~33ms）
- BUSY 已启用内部下拉，未接线时读为 0

---

### 4. MAX98357 I2S 功放 + 喇叭

| 信号 | GPIO | MAX98357引脚 | 说明 |
|------|------|-------------|------|
| BCK | GPIO18 | BCK | I2S 位时钟 |
| LRC | GPIO19 | LRC | I2S 左右声道时钟（WS） |
| DIN | GPIO20 | DIN | I2S 数据线 |
| VIN | **5V** | VIN | ⚠️ 必须 5V |
| GND | GND | GND | 电源地 |
| — | — | OUT+ | 接喇叭正极 |
| — | — | OUT- | 接喇叭负极 |

---

### 5. UART2 — 连接主控板

| 信号 | 本板GPIO | 主控板GPIO | 说明 |
|------|----------|------------|------|
| TX | GPIO17 (UART2 TX) | 主控板 RX | 本板发送，主控板接收 |
| RX | (未使用) | — | 当前单向通信 |
| GND | GND | GND | 共地 |

**UART 参数**: 115200 baud, 8N1

**协议格式**:
```
速度,地点类型,司机ID,驾驶时长(秒)\n

示例: 80,1,1,200\n
地点类型: 0=普通路段, 1=服务区, 2=应急车道
```

---

### 6. UART1 — GPS 模块预留

| 信号 | GPIO | 说明 |
|------|------|------|
| TX | GPIO15 | UART1 原生 TXD (IO_MUX) |
| RX | GPIO16 | UART1 原生 RXD (IO_MUX) |

⚠️ GPIO16 与 SW6 按键共用（按键输入 + UART1 RX 可并存，但 GPS 使能时需注意按键误触）
- UART1 当前空闲，GPS 驱动待实现
- 参数: 9600bps 8N1（典型 GPS NMEA），可调整

---

### 7. 电源

| 引脚 | 连接 |
|------|------|
| 5V | USB供电 或 外部5V → SYN6288 / MAX98357 |
| 3V3 | 板载 3.3V 输出 → OLED |
| GND | 公共地（所有模块共地！） |

## GPIO 占用总表

| GPIO | 功能 | 方向 | 备注 |
|------|------|------|------|
| GPIO2 | 按键5 (司机切换) | 输入 | 内部上拉 |
| GPIO4 | I2C SDA | I/O | OLED 数据线 |
| GPIO5 | I2C SCL | 输出 | OLED 时钟线 |
| GPIO7 | SYN6288 BUSY | 输入 | 内部下拉 |
| GPIO8 | 按键1 (速度0) | 输入 | 内部上拉 |
| GPIO9 | 按键2 (速度80) | 输入 | 内部上拉 |
| GPIO11 | 按键3 (速度150) | 输入 | 内部上拉 |
| GPIO12 | 按键4 (地点) | 输入 | 内部上拉 |
| GPIO13 | SYN6288 TX | 输出 | 软件UART, 不占硬件 |
| GPIO15 | GPS TX (预留) | 输出 | UART1 原生, 空闲 |
| GPIO16 | 按键6 (+60min) / GPS RX | 输入 | 与 GPS RX 共享 |
| GPIO17 | UART2 TX → 主控 | 输出 | 115200bps |
| GPIO18 | I2S BCK | 输出 | MAX98357 |
| GPIO19 | I2S LRC | 输出 | MAX98357 |
| GPIO20 | I2S DIN | 输出 | MAX98357 |

**空闲 GPIO**: 1, 3, 6, 10, 14, 21, 38-48

## 接线检查清单

上电前确认:
- [ ] 所有模块 GND 已共地
- [ ] SYN6288 VCC = **5V**（万用表量！不是 3.3V）
- [ ] MAX98357 VIN = **5V**
- [ ] OLED VCC = 3.3V
- [ ] SYN6288 RX ↔ GPIO13 导通
- [ ] SYN6288 BUSY ↔ GPIO7 导通
- [ ] 按键接线：SW1→GPIO8, SW2→GPIO9, SW3→GPIO11, SW4→GPIO12, SW5→GPIO2, SW6→GPIO16（另一端接 GND）
- [ ] UART2 TX (GPIO17) → 主控板 RX，GND 共地
- [ ] SYN6288 红色电源灯亮起

## 首次上电调试

1. 烧录固件，串口监视器 115200 波特率观察日志
2. 确认 `SYN6288 Ready: TX=GPIO13 BUSY=GPIO7 9600bps soft-UART`
3. 输入 `test_syn` 运行诊断，应听到 "Hi" 和 "系统初始化完成"
4. 依次按 6 个按键，观察 OLED 变化和 UART 输出
5. 按键 3（超速）/ 4（服务区/应急车道）/ 5（切换司机）/ 6（驾驶时长）应有对应语音播报
