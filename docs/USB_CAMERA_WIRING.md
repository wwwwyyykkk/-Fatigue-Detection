# USB 摄像头接线指南

## 硬件接线表

| 摄像头模块 (CAM12-720P-V2) | ESP32-S3 开发板 | 说明 |
|--------------------------|----------------|------|
| VCC (5V) | 5V 输出引脚 | 摄像头供电（约 300mA） |
| D- (白色) | GPIO 19 | USB 数据负 |
| D+ (绿色) | GPIO 20 | USB 数据正 |
| GND (黑色) | GND | 共地 |

## 扬声器连线

扬声器通过两根线直接连接到摄像头模块上（摄像头自带扬声器功能），**不经过 ESP32**。

## USB-PHY 冲突说明

ESP32-S3 的内部 USB PHY 被两个控制器共用：

| 控制器 | 用途 |
|--------|------|
| **USB-Serial-JTAG** | 默认串口调试 + JTAG（板载 USB 口） |
| **USB-OTG** | USB 主机模式（接摄像头） |

`usb_host_install()` 会在运行时自动将 PHY 从 USB-Serial-JTAG 切换到 USB-OTG。

**后果：** 板载 USB 串口会立即失效，无法再通过它看日志或烧录。

## 调试方式：外部 UART

需使用 **USB 转 UART 适配器**（如 CH340G、CP2102、FT232）：

| ESP32-S3 引脚 | 功能 | 接外部 UART |
|--------------|------|------------|
| GPIO 43 | TXD0 | 接 UART 的 RX |
| GPIO 44 | RXD0 | 接 UART 的 TX |
| GND | GND | 接 UART 的 GND |

波特率：**115200**

## 烧录方式

由于 PHY 切换是运行时发生的，**烧录过程不受影响**：

1. 正常通过板载 USB 口烧录（烧录时摄像头不要插）
2. 烧录完成后拔掉 USB 线
3. 接好外部 UART 线（GPIO43/44）
4. 插上摄像头
5. 通过外部 UART 供电或单独给开发板上电
6. 通过外部 UART 查看串口日志

## 电源要求

- USB 摄像头典型工作电流：200-500mA
- ESP32-S3 开发板 5V 引脚输出能力有限
- **建议使用 5V/2A 以上的电源适配器**
- 如果出现摄像头反复重启，可能是供电不足，需换更大功率电源

## 摄像头规格 (CAM12-720P-V2)

- 接口类型：USB UVC（免驱）
- 视频格式：MJPEG
- 最大分辨率：720p（实际以协商结果为准）
- ESP32-S3 带宽受限（USB 1.1 Full Speed），推荐 640×480@15fps MJPEG
- 自带扬声器（通过 USB UAC 协议通信）
